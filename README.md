<h1>📱 QR Code Generator in Python:</h1>

A simple, efficient, and customizable Python script that generates high-resolution QR codes linking directly to your GitHub profile, portfolio, or any custom URL. Built using the qrcode and Pillow libraries.

<h1>✨ Features:</h1>

1.Custom Configurations: Easily adjust QR code size, error correction level, border width, and colors.
2.Fast Execution: Generates crisp, scannable PNG image files in seconds.
3.Cross-Platform Compatibility: Scannable using Google Lens, standard smartphone camera apps, or dedicated QR scanners.

<h1>🛠️ Tech Stack & Requirements:</h1>

Language: Python 3.12+

Dependencies:
1. qrcode — QR code generation
2. Pillow — Image processing backend (PIL)
